# Gerenciador de Tarefas

Aplicativo web minimalista desenvolvido para organizar o dia a dia de forma rápida e prática.

Acesse os documentos detalhados na pasta [docs/](docs/):
- [Termo de Abertura (Project Charter)](docs/project-charter.md)
- [Requisitos Funcionais e Não Funcionais](docs/requisitos.md)
- [Casos de Uso](docs/casos-de-uso.md)
- [Histórias de Usuário](docs/user-stories.md)

## Como Executar Localmente
1. Clone este repositório.
2. Abra a pasta `src/` e dê um duplo clique no arquivo `index.html` para abrir no seu navegador.
